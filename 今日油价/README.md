# 今日油价 (Scripting 原生小组件与配置 App)

> **一键导入安装**：[点击安装到 Scripting](https://www.scripting.fun/import_scripts/?urls=%5B%22https%3A%2F%2Fgithub.com%2FSylvanRoe%2FScripting%2Fraw%2Frefs%2Fheads%2Fmain%2F%E4%BB%8A%E6%97%A5%E6%B2%B9%E4%BB%B7%2F%E4%BB%8A%E6%97%A5%E6%B2%B9%E4%BB%B7.scripting%22%5D)

基于现代 iOS 原生视觉规范与高级深色玻璃拟态（Glassmorphism）重塑的桌面油价小组件。

## 视觉与设计特色 (v1.2.0 主次聚焦精细化版本)

- 🖤 **克制深邃的深色玻璃拟态**：
  - 剔除廉价刺眼的过度渐变与高发光饱和度，采用 Apple 原生层级设计。
  - 背景使用 `#161920` 至 `#0D0E12` 的柔和深色质感，卡片采用半透明磨砂玻璃材质（`rgba(255, 255, 255, 0.05)`）。
- 🎯 **中部主次聚焦核心区（60% + 40% 黄金分割）**：
  - **左侧调价深度看板 (60%)**：
    - 状态徽标（`arrow.down` 预计下调）+ 右上角策略胶囊（`建议调价后再加满`）。
    - 核心粗体超大吨价：**`150` 元/吨**。
    - 次级升价换算区间：`约 0.11~0.14 元/升`，层次分明，字阶考究。
  - **右侧主力油品高光聚焦大卡 (40%)**：
    - 用户自定义关注油号（默认 92#，可设 95#/98#/0#），带有专属油滴图标（`drop.fill`）。
    - 价格数字采用 **`title2` 加粗纯白超大字体**（如 `¥8.57`），一瞥即得。
- ⛽ **底部次要油品横向三联轻量胶囊**：
  - 其余三种油品（95#、98#、0#）采用等宽半透玻璃胶囊一字排开，包含油号色标与加粗价格，视觉轻盈、信息完整。
- 🏷️ **顶部状态行与时间胶囊**：
  - 单色极简油枪图标与省份标题（「山东 今日油价」）。
  - 右侧双层轻透胶囊整合调价日期（`10月15日24时`）与倒计时（`14天后`）。
- ⚙️ **设置面板与主力油品自由配置**：
  - 支持全国 31 省市自治区及自动定位。
  - 新增「**主力关注油品**」选择，随心挑选 92#、95#、98# 或 0# 柴油，即时在桌面组件与 App 内大字置顶呈现。
  - 内置中号/小号组件实时预览功能。
